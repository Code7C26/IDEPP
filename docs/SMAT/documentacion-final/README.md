## Cómo pasarlo a Google Docs o PDF

1. Abrir el documento con el link de arriba.
2. Hacer clic en el **nombre del documento** → **Export**.
3. Elegir **Google Docs** (queda una copia en el Drive) o **PDF** para entregar.
4. En Google Docs: aplicar formato APA (Times New Roman 12 o Arial 11, interlineado 2, márgenes de 2,54 cm,
   número de página arriba a la derecha) y actualizar el índice.
