# Acta 26/08/2026 · Qué va a tener el robot

**Asistentes:** Tiziano y Morena
**Modalidad:** presencial, en el colegio

## Temas

1. El diseño del robot.
2. Cómo va a detectar si falta el equipo de protección.
3. Cómo probarlo antes de tener todas las piezas.
4. Qué hace cada uno.

## Decisiones

- Se define el diseño del robot.
- El robot usa **inteligencia artificial** para detectar si a alguien le falta el equipo de protección.
- Para empezar, se prueba la detección con la **cámara del celular**, antes de tener la cámara del robot.
- Cada uno se encarga de un área: **Tiziano**, del software y la web; **Morena**, del hardware y la inteligencia artificial.
